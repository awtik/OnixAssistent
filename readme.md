# **Onix Assistent** with **GUI**

## **Functions**:
- Changing the theme
- Display computer specifications
- Chat with **AI**
- Setting keywords for **voice opening** of applications
- Getting **weather** data in **your city**
- **Voice** search on the **Internet**
- Getting the time
- Music
- Schedule display (for advanced users)
> My schedule is set by default

## **Requirements:**
```
pip install vosk pygame asyncio customtkinter platform cpuinfo psutil wmi os requests webbrowser datetime translate json io pillow g4f pyaudio shutil text2num
```
> [!WARNING]
> Only **Python**, Only **hardcore**

> [!TIP]
> # Using
1. Start **main.py**
2. Close program
3. Move application shortcuts into **C:/Onix/apps**
4. Move thacks into **C:/Onix/tracks**
5. Edit settings.json **(For advanced users!)**
6. **Start main.py and enjoy** !
